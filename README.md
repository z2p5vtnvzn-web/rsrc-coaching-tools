# RSRC · Coaching Tools

一个用于制作动作指导卡片的纯前端 PWA。首次打开后，页面资源会缓存在浏览器；动作内容、历史记录和图片导出均在设备本地处理。上传的照片只用于当前编辑，不会保存到历史记录或 JSON 备份中。

## 使用

- 打开 GitHub Pages 发布地址，首次访问需要联网。
- 在 iPhone 的 Safari 中选择“分享”→“添加到主屏幕”，后续可离线使用。
- 动作卡片支持 2、3、4 图模板、文字自动保存和 1080 / 2160 像素宽 PNG 导出。
- 设置页可导出或导入仅含文字与模板配置的 JSON 备份。

每台设备、每个浏览器的历史记录彼此独立。需要迁移时，请先导出 JSON，再在另一设备导入。浏览器清理网站数据可能删除本地记录。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8786 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8786/ 。静态文件无构建步骤，也不使用第三方运行依赖。

## 会员卡片 · 手法处理

会员卡片支持可编辑标题、会员姓名、日期、前后各一张 3:4 照片、0—10 分疼痛感自评分及处理区域。照片自动叠加工作室水印；文字保存与 JSON 备份包含会员记录，照片仍不写入历史或备份。

## 案例卡片

支持 1—2 张 3:4 照片，单图居中、双图并排，自动添加工作室水印。填写案例标题、日期、主述、处理次数和区域、1—10 分前后不适感自评分；训练记录可开关，开启后填写次数与内容。长文字自动换行，卡片高度随内容增加。文字记录纳入历史与 JSON 备份，照片不保存。
